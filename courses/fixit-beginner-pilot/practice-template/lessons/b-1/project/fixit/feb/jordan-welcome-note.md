# Welcome, new volunteers!

Notes from Jordan for whoever helps out next.

- Volunteers arrive at 10:00 to set up the tables.
- Park in the library car park behind the building, it's free.
- Doors open to the public at 10:30.
- Bring your own tools if you have them; the library lends us extension leads.
- We finish at 1pm and the room has to be clear by 1:30.
- Every item gets a repair card, even if we can't fix it.
