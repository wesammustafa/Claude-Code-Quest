# Millbrook Fixers: standing notes

Kept by Priya. Last edited 9 January 2027.

## How a session runs
- Volunteers set up from the time the room is booked; the public comes in 30 minutes later.
- One item per person until 12:00. After 12:00, second items if a fixer is free.
- Every item gets a repair card: what is wrong, what we tried, whether it is fixed.
- Free. There is a donations jar for parts.

## What we do not accept (safety, agreed with the library in November 2026)
- Microwaves
- Gas appliances of any kind
- Anything with a swollen or cracked battery
- Items that need mains rewiring inside the casing

## Booking
- The public books through the library's events page. Walk-ins only if there is space at 11:00.
- We cap sign-ups so that volunteers plus visitors stay within the room's limit.
