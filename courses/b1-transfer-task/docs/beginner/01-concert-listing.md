# The concert listing

<sub>**Beginner** · Lesson 1 of 1 · about 10 minutes · Needs: [the task index](README.md) · Verified against Claude Code v2.1.325 (stable) documentation on 2026-11-24, pilot not yet re-run in a real session</sub>

Sam at the Hollin Arts Centre prints the choir's listing exactly as you send it. Make `concert/listing.md` with Claude's help, and send only what you'd stand behind.

## The files

| File | What it is |
|---|---|
| `concert/REQUEST.md` | Sam's request |
| `concert/venue-confirmation.md` | the Centre's signed hire confirmation, 2 March 2027 |
| `concert/committee-minutes-2027-02-24.md` | the choir committee's minutes, 24 February 2027 |
| `concert/programme-2026.md` | last year's concert programme |

## Your turn

1. **Get Claude's help.** Read Sam's request, start Claude in the `project/` folder, and ask it for what you need.
2. **Ask anything else** you want to know before you decide (optional).
3. **Make it ready to send.** Edit `concert/listing.md` in the files tab until it's what you'd send Sam, and end it with a line that starts "Ready because".

In this practice workspace Claude's replies are written in advance. With real Claude Code, a reply comes from what the model reads in your files, and it can be wrong in the same ways.

## Check

The Lesson's check reads only that the sources are unchanged and that the listing says why it's ready. It doesn't judge whether the listing is right.
