# Beginner: one attendee guide you can defend

<sub>**Beginner** · about 2 hours 15 minutes · Verified against Claude Code v2.1.325 (stable) documentation on 2026-11-24, pilot not yet re-run in a real session</sub>

Six lessons, the capstone last, built around the Millbrook Fixers, a volunteer repair workshop that meets at Millbrook Library. They run in Questerm's practice workspace. You need no terminal, Git or programming experience.

## You're ready for this level if you can

- [ ] Read a short email and say what it promises.
- [ ] Type a sentence and press Enter.

## Lessons

1. [Start Claude Code and check what it tells you](01-start-and-check.md)
2. [Give Claude a clear job](02-give-claude-a-clear-job.md)
3. [Check every claim before anyone relies on it](03-check-every-claim.md)
4. [Steer, undo and start fresh](04-steer-undo-and-start-fresh.md)
5. [Hand it over: show it is ready](05-hand-it-over.md)

## Capstone

[The March attendee guide](capstone.md): write the guide members of the public use to decide whether to come, from a signed booking, two sets of notes and an old flyer that disagree, and show Maya why every line can be trusted.

## Optional labs

[From request to commit in code](lab-request-to-commit.md): the code version of lesson 2, on the Fix-It group's website repository. Check that Ade's patch to the link checker does only what it says, fix it with a test that fails on his version, read the diff and commit; then fix a silent missing folder test first. No core lesson or capstone depends on it.
