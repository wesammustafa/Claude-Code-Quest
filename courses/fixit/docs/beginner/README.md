# Beginner: one attendee guide you can defend

<sub>**Beginner** · about 1 hour · Verified against Claude Code v2.1.325 (stable) documentation on 2026-11-24, pilot not yet re-run in a real session</sub>

**Pilot.** This is a three-lesson pilot of the redesigned Beginner level, built around the Millbrook Fixers, a volunteer repair workshop that meets at Millbrook Library. It runs in Questerm's practice workspace. You need no terminal, Git or programming experience.

## You're ready for this level if you can

- [ ] Read a short email and say what it promises.
- [ ] Type a sentence and press Enter.

## Lessons

1. [Start Claude Code and check what it tells you](01-start-and-check.md)
2. [Give Claude a clear job](02-give-claude-a-clear-job.md)
3. [Check every claim before anyone relies on it](02-check-every-claim.md)
4. [Steer, undo and start fresh](04-steer-undo-and-start-fresh.md)
5. [Hand it over: show it is ready](05-hand-it-over.md)
