## ladder

### the pages in `samples/` link to `library.example/whats-on/` instead of `library.example/events/` at `HEAD`, changed by commits made in this lab that touch nothing outside `samples/`
- narrow "but not in your working tree": Is the migration still uncommitted?
- narrow "still links to": Is an old link still in a page at HEAD?
- narrow "still link to": Are old links still in the pages at HEAD?
- narrow "no longer links to": Did a link change more than its /events/ part?
- narrow "outside `samples/`": Did the commit that changed the links also change another file?
- narrow "has no link to": Is the check running in this lab's practice copy?
- hint: "The grep from the goal lists what is left: `git grep -n 'library.example/events/' -- samples`."
- back: W2 The goal names the grep and the tests.

### a committed workflow takes its folder from `args`, has an agent look at each file and a second agent check each finding on its own, returns only the confirmed findings, and asks no agent to change a file
- narrow "There is no workflow script": Did you save the run from the progress view to the project location?
- narrow "isn't committed": Does git status still list the saved script as new?
- narrow "doesn't take its folder from `args`": Does the committed script still name its own folder?
- narrow "never reads `args`": Does the committed script still name its own folder?
- narrow "declares its own `args`": Does the script declare a variable named args?
- narrow "doesn't start with `export const meta`": Does code come before the meta line?
- narrow "anything but literal values": Does the meta object hold a variable or a call?
- narrow "needs a non-empty": Does the meta object lack a name or a description?
- narrow "doesn't compile": Does the committed script have a syntax error?
- narrow "stops with an error": What does the error the script stops with name?
- narrow "on its own": Does each file get an agent of its own?
- narrow "without a second agent": Does a second agent check what the file agents find?
- narrow "findings at once": Does each finding get its own checking agent?
- narrow "sees the finding": Does every finding reach a checking agent?
- narrow "a finding its checking agent refuted": Does the script return a finding its checker refuted?
- narrow "a finding its checking agent confirmed": Does the script leave out a confirmed finding?
- narrow "asks an agent to change code": Does a prompt in the script ask for a fix?
- narrow "no module, file or shell access": Does the script reach for a module or a file itself?
- hint: "The line under this item names the part of the script to change: ask Claude to change it, then commit the fix."
