- code: lines 13-20 point 20
```yaml
name: Link check report
on: workflow_dispatch
permissions:
  contents: read
jobs:
  report:
    runs-on: ubuntu-latest
    timeout-minutes: 10
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-node@v7
        with:
          node-version: lts/*
      - uses: anthropics/claude-code-action@v1.0.258
        with:
          anthropic_api_key: ${{ secrets.ANTHROPIC_API_KEY }}
          github_token: ${{ github.token }}
          display_report: true
          prompt: Run `npm --prefix project run linkcheck -- samples` and explain each broken link it reports, in one sentence each. Change no file.
          claude_args: --max-turns 5 --allowedTools "Bash(npm --prefix project run linkcheck *)"
```
- note: "Every limit is in the file: the turns, the one command Claude may run, the read-only token and the time."
- hint: "Find the line that says which command Claude may run, and the one that caps its turns."
