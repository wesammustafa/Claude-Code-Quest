- why: "Maya is about to publish pages a run said it updated. One of them still tells wheelchair users the lift works."
- can: "recognise a run that reports success but didn't finish"
- can: "stop its output being used, and find the cause in the run's own evidence"

## warm-up

### R1 | Warm-up | A rule that keeps a run out
- tier: challenge
- skill: limit-run
- from: a-7
- beat: ask
- ask: A nightly run's bounds allow it to read everything in `summer/`, and Priya's roster sits in `summer/private/`. What keeps the run out of the roster?
- wrong: Nothing more: the allow list doesn't name the roster, so the run can't read it
- because: "`Read(./summer/**)` covers `summer/private/` too. An allow rule for a folder reaches everything inside it."
- right: A deny rule for private folders, which wins over any allow rule
- wrong: A line in the run's task saying not to open it
- because: "A task is a request, not a rule. With nobody watching, only the bounds decide what the run can do."
- reveal: "Allow what the run needs, and deny what it must never touch. A deny rule always wins."

### R2 | Warm-up | Two sources disagree about a room
- tier: challenge
- skill: reconcile
- from: a-8
- beat: ask
- ask: The signed booking of 19 May puts June in Room B. The venue's email of 10 June says the session has moved to Room A. Which do you act on?
- wrong: The signed booking: a signature beats an email
- because: "Both come from the venue. The kit's rule is that the newest written confirmation wins on what it covers."
- right: The email: it's the venue's newer written word on the same session
- wrong: Ask Claude for a third reading, and go with the majority
- because: "A third opinion is another vote. What decides it is what each source is, and how recent it is."
- reveal: "Scope and date decide most disagreements: check what each source covers, and whether anything is newer."

### R3 | Warm-up | What a run will cost
- tier: challenge
- skill: check-cost
- from: a-7
- beat: ask
- ask: Before a refresh goes on a timer, how do you find out what it will cost?
- wrong: Set no spend limit, and read the bill afterwards
- because: "With nobody watching, a run with no limit spends until it finishes. The limit is what stops it."
- wrong: Ask Claude in a normal session how much the run will cost
- because: "Claude can't know before the run happens. Only a run shows what it costs."
- right: Run it on one page and read its cost estimate
- reveal: "A slice shows the cost, and what the bounds stop, before anything goes on a timer."

## steps

### W1 | Worked example step 1 of 5 | Stop the output being used
- tier: hinted
- skill: headless-run
- where: editor
- beat: ask
- ask: The runner's report says `success` with one permission denial, and Maya is starting layout for noon. What do you do first?
- wrong: Nothing: success means the pages are done
- because: "`success` means the run ended normally. It says nothing about whether every change it needed was allowed."
- wrong: Rerun the whole refresh with wider permissions, so nothing is denied
- because: "You don't know yet what was denied or why, and widening the bounds removes the guard that just told you something was wrong."
- right: Tell Maya to wait, then find out what was denied and which pages it affects
- reveal: "Stop the output being used, then find the cause. A one-line message costs nothing; a wrong page on the library's website costs a lot."
- beat: do
- verify: self

- goal: "Send Maya one line: "Hold the summer pages, the overnight run hit a problem. I'll tell you by 10:00 which are good.""
- why: "A run's output is only dangerous once someone relies on it. Stopping its use is the cheapest move you have, and the easiest to undo."
- hint: "Who is about to use the pages, and what would stop her for now?"
- note: "Maya replies at 07:32: "OK, holding.""

- tier: hinted
- skill: stop-run
