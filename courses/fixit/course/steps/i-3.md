## ladder

### the committed changelog skill runs a smaller model or a lower effort than the session's default, Opus at medium, and says why
- narrow "Set the model": Which model costs less than the session's for a line you will review?
- narrow "Set the effort": How long does a one-line entry from an exact diff need Claude to think?
- narrow "isn't an effort level": Is the effort line one of the levels Claude Code knows?
- narrow "is larger than": Does a one-line entry you review need a bigger model than the session's?
- narrow "isn't a model alias": Is the model line an alias Claude Code knows, spelled as the lab gives it?
- narrow "is higher than": Does this entry need more thinking than the session gives?
- narrow "costs no less": Which of the two settings did you make cheaper?
- narrow "has no heading": Is the heading still in the skill?
- narrow "Write one line": What makes a changelog entry routine work?
- narrow "isn't committed yet": Did the commit include the changelog skill?
- narrow "is not committed": Is the changelog skill in a commit yet?
