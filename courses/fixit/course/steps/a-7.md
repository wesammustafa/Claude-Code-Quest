## intro

- why: "At 02:00 nobody is there to press No. Whatever a run is allowed to do, it will do, and its summary will still say success."
- can: "decide whether a run should be unattended at all"

## warm-up

### R1 | Warm-up | A one-off change on four pages
- tier: challenge
- skill: pick-pattern
- from: a-2
- beat: ask
- ask: Maya wants the new battery rule added to the four summer pages, once. Sam suggests a scheduled run so it's done tonight. What do you tell him?
- wrong: Yes: a scheduled run means nobody has to remember to do it
- because: "A scheduled run costs something every time it goes off. For a one-off change, that buys nothing."
- right: No: run it once now, then read the four pages
- wrong: Yes, as long as it runs in its own worktree
- because: "A worktree keeps sessions from overwriting each other. It doesn't make a timer useful for a job that happens once."
- reveal: "A scheduled run is Claude on a timer with nobody watching. It fits a job that recurs, not a one-off change."

### R2 | Warm-up | Two reviews that disagree
- tier: challenge
- skill: reconcile
- from: a-8
- beat: ask
- ask: Two reviews of the August page disagree about the accessible toilet. One read the April notes; the other read Kofi's email of 25 May. Which do you act on?
- right: The one that read Kofi's email: it's newer, and it covers the toilet
- wrong: The one that flags a problem, to be safe
- because: "A flag is only as good as what the reviewer read, and the April notes are older than Kofi's email."
- wrong: Ask Claude for a third review, and go with the majority
- because: "A third opinion is another vote. What decides it is what each one read, and how recent that is."
- reveal: "Scope and date decide most disagreements: check what each reviewer read, and whether anything is newer."
