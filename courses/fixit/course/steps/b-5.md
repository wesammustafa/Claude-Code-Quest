## warm-up

### R1 | Warm-up | A new job, a long conversation
- tier: challenge
- skill: clear
- from: b-4
- beat: ask
- ask: Yesterday's long conversation made the February guide. Today you start the volunteer rota, which needs none of it. What do you do with the conversation?
- wrong: Compact it, so the rota starts from a summary
- because: "Compacting is for carrying on the same job with less history. The rota needs none of this conversation, and a summary of it would sit in the way."
- wrong: Keep going in it, since more context can't hurt
- because: "Old history about the guide crowds out what the rota needs, and it costs more on every message."
- right: Clear it, and start the rota with nothing in it
- reveal: "Unrelated job, clean start: `/clear` starts an empty conversation, and the guide is saved in its file, where it belongs. The old conversation can still be found with `/resume`."

### R2 | Warm-up | Two sources, two times
- tier: challenge
- skill: ask
- from: b-6
- beat: ask
- ask: The flyer and the partner's listing say doors at 10am. The January meeting notes say the public comes in from 10:30. Which time goes in the guide?
- right: 10:30, from the meeting notes
- wrong: 10am, since two sources say so
- because: "Counting files isn't weighing them: the newest file about this session, from the people who run it, wins."
- wrong: Both times, so nobody is caught out
- because: "A draft can be a faithful mix of its sources and still be wrong, when some of those sources are out of date or second-hand."
- reveal: "Counting files isn't weighing them: the newest file about this session, from the people who run it, wins."

## steps

### W1 | Worked example step 1 of 2 | Why a fresh session
- tier: hinted
- skill: clear
- where: terminal
- beat: predict
- ask: The guide is finished. Who should do the final check before Maya posts it?
- option: The same session that wrote it, asked whether it's all correct
- because: "That session remembers why it wrote each line, and it tends to agree with itself. It will check what it meant, not what's on the page."
- right: A fresh session that sees only the files and your written criteria
- option: Nobody: every line was already checked, one by one
- because: "Every line of the guide was checked. Maya is printing two documents."
- reveal: "It knows nothing you didn't write down, which is exactly the position Maya, or next month's you, will be in."
- beat: do
- verify: self
- goal: "Start Claude in the `project/` folder"
- run: "claude"
- note: "A new session starts with no memory of any earlier conversation, and so does this one after `/clear`. It knows only what's in the files."
- note: "If Claude Code asks whether you trust this folder, accept it: this is your own practice copy, as in Lesson 1."

### Y2 | Your turn step 2 of 5 | Fix it, or note it?
- tier: challenge
- skill: ask
- where: editor
- beat: ask
- ask: The door sign says 10am. Maya prints it tomorrow. What do you do?

- because: "**Still open** is for what the evidence can't settle yet. This one is settled: the sign is wrong."
- wrong: Ask Claude whether 10am is close enough
- because: "You already have the evidence. Asking again gets a second opinion, not a better one."
- right: Fix the sign, then write down which source wins
- reveal: "Fix what's wrong, then write down the rule the fresh session had to guess, so the next check doesn't have to."
