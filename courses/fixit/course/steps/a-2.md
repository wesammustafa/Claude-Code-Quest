### W2 | Worked example step 2 of 4 | Compare the ways to run it
- tier: guided
- skill: pick-pattern
- where: claude
- beat: do
- verify: self
- done-label: I read the five ways
- goal: "Five ways Claude Code can run work, compared for this job:"
- note: "One session, in order: Claude edits each page, then the schedule. It uses the least, about four turns. Reasonable: the baseline to beat."
- note: "Subagents, one per page, then the schedule in the main session. A subagent is a helper Claude starts, with a conversation of its own. It uses more, you wait less, and the main conversation stays short. Best fit: each page reads its own sources, and the schedule waits."
- note: "Parallel sessions, each in its own worktree, a separate copy of the folder: the most setup, and a merge afterwards. Refuse: it pays only when sessions would edit the same files at once, and nothing collides here."
- note: "A saved workflow, a script that runs many subagents in stages: you write it and read it first. Refuse: it pays for a job too big for one conversation, not for three pages."
- note: "A scheduled run, Claude on a timer with nobody watching: it costs something every time. Not for a one-off change."

### Y1 | Your turn step 1 of 3 | Triage: a tiny change everywhere
- tier: hinted
- skill: pick-pattern
- where: claude
- beat: ask
- ask: Maya wants the heading "We can't take" renamed to "Please leave at home" on all four pages. How do you run it?
- right: One session: one request, then check the four files
- wrong: A subagent for each page, then the schedule after them
- because: "Each subagent re-reads the kit's memory and its page to change two words. The cost of splitting is bigger than the job."
- wrong: A saved workflow, so you can reuse it next time
- because: "Renaming a heading isn't a recurring job in stages. A workflow is a script you'd have to write and read before it runs."
- reveal: "Small, mechanical and the same everywhere: one session is cheapest and easiest to check."
- hint: "How much work is each page, and what would splitting add to it?"

### Y2 | Your turn step 2 of 3 | Triage: two people, the same files
- tier: hinted
- skill: pick-pattern
- where: claude
- beat: ask
- ask: Sam wants to rework the August page this afternoon in his own Claude session, while you rework the schedule and the August booking line in yours. What do you do?
- wrong: Both of you work in the same folder, and Claude notices the other's edits
- because: "Two sessions in one checkout can overwrite each other's edits without either of them noticing."
- wrong: Each of you works in a separate worktree, and you merge at the end
- because: "Worktrees stop the two sessions overwriting each other mid-edit, but you both change `august.md`, so the merge conflicts anyway and someone resolves it by hand."
- right: Sam owns the August page; you own the schedule and wait for it
- reveal: "Parallel tools don't fix overlapping ownership: split by file, and let the dependent file wait."
- hint: "Which file do both of you change, and which file waits for another?"
