## ladder

### `fixit/CLAUDE.md` is short and gives the rules that hold every month: which source wins, how to publish an unconfirmed detail, and whose number goes on a public page
- narrow "There's no": Did Claude save `fixit/CLAUDE.md`, in the folder the session started in?
- narrow "lines. Every line": Which lines could Claude find by looking, or hold only this month?
- narrow "which source wins": When the booking, the notes and the flyer disagree, which does Claude believe?
- narrow "puts": Which source comes first: the venue's, ours, or an old flyer?
- narrow "nobody has confirmed": What did March decide about the lift?
- narrow "not who to call": Who answers the public's questions?
- narrow "private numbers": Whose number goes on a public page?

### `fixit/CLAUDE.md` holds no event facts: no dates, hours, room limits, personal numbers or folder tour
- narrow "There's no": Did Claude save `fixit/CLAUDE.md`, in the folder the session started in?
- narrow "room limit": Is that limit true at every venue?
- narrow "a date": Is that date true every month?
- narrow "hours": Does every venue open at the same time?
- narrow "gives 555": Can a session repeat a number memory gives it?
- narrow "tour": Can Claude see the folders for itself?

### Claude's auto memory gives no room limit
- narrow "still says": Is that line true for Northside, or for Room A?

### a rule in `fixit/.claude/rules/` loads only for the files it covers, and every scoped rule matches a file in `fixit/`
- narrow "There's no rule": Where does an instruction go that should load only sometimes?
- narrow "has `paths:`": When should this rule load?
- narrow "It will never load": Which files in `fixit/` does the pattern name?
- hint: "If the rule never appears, compare its `paths:` with the real file names in `fixit/`, fix the pattern in the files tab, and start a new session."
- bottom: "paths: ['*/attendee-guide.md', 'public/**']"
- back: Y1 Compare the rule's paths with the real file names in the fixit folder.

### `fixit/march/access-note.md` says step-free access is being confirmed, and gives only the library's public number
- narrow "There's no": Did a new session write `fixit/march/access-note.md`?
- narrow "as if it were settled": Did the session that wrote the note start after you saved `CLAUDE.md`?
- narrow "doesn't say": What does `CLAUDE.md` say about a detail nobody has confirmed?
- narrow "gives 555": Whose number goes on a public page?
- narrow "no number": Who should people call about access?
