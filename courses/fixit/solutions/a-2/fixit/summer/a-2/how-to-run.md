# How to run it: two summer jobs

For each job, write `subagents` or `agent team` first after "Run it with:", then "because" and your reason.

## Job 1: the easy-read pages

Each helper reads its own session's booking and the May notes, writes one easy-read page beside it, and reports back.

Run it with: subagents, because each helper only needs its own session's sources and reports back, so a team would cost more for nothing.

## Job 2: a fallback for July

If the Room B lift stops working before 10 July, should the July session move to Room A, move to Northside or change its date? Priya wants three helpers, each making the case for one option, to challenge each other's case and agree one plan between them before they bring it to her.

Run it with: agent team, because the three helpers have to answer each other's objections and agree a plan among themselves, not just report back to Priya.
